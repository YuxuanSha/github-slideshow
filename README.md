## Flash Note mockup preview

The standalone `note-home.html` file (located in the repo root) recreates the provided Flash Note home screen. You can find it directly in the repository file list, or view it in two ways:

1. Local preview: From the repo root, open `note-home.html` in a browser (for example, double-click the file or run `open note-home.html` on macOS). Keep the browser window narrow (around 390px wide) to match the mobile-style layout.
2. GitHub Pages: If this repository has GitHub Pages enabled, open `https://<your-github-username>.github.io/github-slideshow/note-home.html` (replace `<your-github-username>` with your username) to view the page online.

## Exporting to a separate `codex` branch repository

A ready-to-push copy of the Flash Note mockup lives in `codex-repo/`. To publish it as a standalone repository on a `codex` branch:

1. Copy the `codex-repo` folder outside this repo.
2. Run the commands listed in `codex-repo/README.md` to initialize a new repo, create the `codex` branch, and push to GitHub.
